The standards

The measurements behind a safe, comfortable home, with the source for each one.

Why we use the ADA for homes

The Americans with Disabilities Act generally doesn't apply to private houses. But its 2010 Standards are the most widely tested set of accessibility measurements there is, so we use them as a guide. Your local building code still applies.

Toilet distance from side wall16–18 inFrom the wall to the center of the toilet, so a side grab bar is in reach.ADA 2010, §604.2
